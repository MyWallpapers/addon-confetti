# Celebrate

Une courte gerbe de confettis, déclenchée à l’apparition ou avec le bouton de réglage. Aucun effet permanent.

Aucun réseau, accès natif, collecte ou service privé du cœur. L’animation CSS est finie ; la préférence de réduction des mouvements remplace le mouvement par une gerbe fixe.

Installez avec `pnpm install`, compilez avec `pnpm build`, vérifiez avec `pnpm test`, puis utilisez `mywallpaper dev` pour appairer le projet à MyWallpaper. Après `mywallpaper check`, poussez ce dépôt public avec un tag immuable de même version que le manifeste et publiez depuis l’application.
